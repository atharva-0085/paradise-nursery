# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built using React and Redux. The application allows users to browse a variety of houseplants organized into different categories and add plants to a shopping cart.

## Features

- Browse houseplants by category
- View plant images, names, and prices
- Add plants to the shopping cart
- Dynamically update cart quantities
- Increase or decrease item quantities
- Remove items from the cart
- View individual item costs and total cart cost
- Navigate between the Home, Plants, and Cart pages

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- HTML
- CSS
